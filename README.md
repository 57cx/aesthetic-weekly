## 每日一课

2026-11-13 起，课程由每周四题改为每日一课。一天只有一个题材太少，所以每个日期要有 **2 到 6 个题材**，数量按这一课的内容来定，并围绕同一件事情。已经发布的周更期次保持原样。每一天仍是一个日期文件夹：

- `今日导读.md` 与 `今日导读.pdf`，导读要覆盖当天全部题材
- 2 到 6 个题材文件夹：各含 `01.jpg`–`05.jpg`、`解读原稿.md`、`《题材_点评与思考》.pdf`
- `sources.json` 与 `verification.json`

每个题材仍是 5 张 Wikimedia Commons 范例。日与日、日与周之间不重复使用照片。没有 EXIF 的拍法写“（推测）”。每张范例沿用九项解读：明暗、对焦、快门、构图、色彩、光线、机位、主题情绪、学习模仿，并给出当天能用 Z30 套头完成的练习。

`tools/render_issue.py` 会拒绝 2026-11-13 及以后的每日课程落在 2 到 6 个题材之外，规则写在 `tools/daily_rules.py`。下一天在写好导读、各题材原稿、五张图和 `sources.json` 之后生成 PDF：

```bash
python tools/render_issue.py 2026-11-14 --font /path/to/NotoSansSC-Regular.ttf --write-verification
```

脚本读取该日期下的导读 Markdown、各题材《解读原稿.md》和 `sources.json`，嵌入 Noto Sans SC 子集。字体不放进仓库。2026-11-07 的更正版仍用 `tools/render_issue_2026_11_07.py`，以免把修订说明写进以后的每日 PDF。

全年课程规划见 [curriculum.md](curriculum.md)。

照片来自 Wikimedia Commons，作者和授权信息写在各期 PDF 中。没有 EXIF 的照片，拍法标注为“（推测）”。
